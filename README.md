# League of Logins

Downloads for League of Logins. This repository only holds the installer and update packages, no source code.

## Installieren

1. Unter [Releases](../../releases) die neueste Datei `LeagueOfLogins-…-Setup.exe` laden.
2. Die Datei starten. Die App installiert sich ohne Rückfragen und startet danach.
3. Updates holt sich die App ab dann selbst.

## Windows-Warnung beim ersten Start

Die App ist (noch) nicht signiert. Windows meldet deshalb „Der Computer wurde durch Windows geschützt“. Klicke auf **Weitere Informationen** und dann auf **Trotzdem ausführen**. Das ist nur beim ersten Start der Setup.exe nötig.
